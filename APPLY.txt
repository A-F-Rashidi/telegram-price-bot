نسخه MULTI-SOURCE

تغییرات:
- Nerkh.io به‌عنوان منبع اول حفظ شد.
- TGJU بدون API Key به‌عنوان Fallback دوم اضافه شد.
- Navasan/GitHub بدون API Key به‌عنوان Fallback سوم اضافه شد.
- اگر یک منبع ناقص باشد، فقط نمادهای گمشده از منبع بعدی پر می‌شوند.
- آخرین مقدار D1 برای قطع کامل منابع حفظ می‌شود.
- /whoami برای گرفتن Telegram User ID اضافه شد.
- /setnerkh برای وارد کردن API جدید Nerkh از داخل ربات اضافه شد.
- /nerkhstatus برای دیدن وضعیت منابع اضافه شد.
- /clearnerkh و /cancel اضافه شدند.
- Token ذخیره‌شده با TELEGRAM_WEBHOOK_SECRET به AES-GCM رمزگذاری می‌شود.
- فقط TELEGRAM_ADMIN_USER_ID اجازه مدیریت API دارد.
- Tokenهای منقضی 401/402/403 علامت‌گذاری می‌شوند تا هر دقیقه دوباره فراخوانی نشوند.
- 21 تست موفق.

مرحله لازم بعد از Deploy:
1) در چت خصوصی ربات /whoami را بفرست.
2) عدد برگردانده‌شده را یک‌بار در Cloudflare با نام TELEGRAM_ADMIN_USER_ID تنظیم کن.
3) از این به بعد برای API جدید فقط /setnerkh را داخل ربات بفرست.
