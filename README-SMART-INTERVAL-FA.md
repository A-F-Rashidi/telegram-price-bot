# نسخه سه‌منبعه ربات قیمت تلگرام

این نسخه برای جلوگیری از خوابیدن ربات، سه منبع قیمت را به ترتیب اولویت استفاده می‌کند:

1. **Nerkh.io** — منبع اصلی، وقتی API Token معتبر باشد.
2. **TGJU** — منبع رایگان بدون API Key.
3. **Navasan/GitHub** — آینه رایگان داده‌های Navasan روی GitHub، به‌عنوان آخرین Fallback.

اگر یک منبع فقط بخشی از قیمت‌ها را برگرداند، ربات فقط نمادهای گمشده را از منبع بعدی پر می‌کند. اگر هر سه منبع برای یک نماد موقتاً در دسترس نباشند، آخرین مقدار سالم ذخیره‌شده در D1 نمایش داده می‌شود و با هشدار «آخرین مقدار ذخیره‌شده» مشخص می‌شود.

## نمادهای فعلی

- دلار
- یورو
- تتر
- طلای ۱۸ عیار
- سکه امامی

قواعد ارسال قبلی حفظ شده‌اند:

- دلار، یورو، طلای ۱۸ و سکه امامی: هر تغییر واقعی
- تتر: حداقل ۱۰۰ تومان تغییر نسبت به آخرین قیمت منتشرشده
- حداقل فاصله بین دو پیام کانال: ۵ دقیقه
- با تغییر یک نماد، هر پنج قیمت در پیام کانال نمایش داده می‌شوند
- `/start` و `/price`: آخرین داده موجود در D1 را فوراً نشان می‌دهند

# مدیریت Nerkh API از داخل تلگرام

بعد از این نسخه دیگر برای هر بار تمدید Nerkh لازم نیست Secret را در Cloudflare عوض کنید.

## مرحله یک‌باره: مشخص‌کردن ادمین ربات

بعد از Deploy، در چت خصوصی ربات بفرستید:

```text
/whoami
```

ربات Telegram User ID شما را نشان می‌دهد.

این عدد را فقط یک بار در Cloudflare Worker به‌صورت Variable/Secret با نام زیر تنظیم کنید:

```text
TELEGRAM_ADMIN_USER_ID
```

از آن به بعد فقط همین User ID اجازه تغییر API را دارد.

## وارد کردن Nerkh Token جدید

در چت خصوصی ربات بفرستید:

```text
/setnerkh
```

ربات از شما Token جدید را می‌خواهد. پیام بعدی را فقط خود Token بفرستید.

ربات تلاش می‌کند پیام حاوی Token را سریع حذف کند، Token را با استفاده از `TELEGRAM_WEBHOOK_SECRET` رمزگذاری می‌کند و نسخه رمز‌شده را در همان جدول `bot_state` دیتابیس D1 ذخیره می‌کند.

می‌توانید Token را مستقیم هم بفرستید:

```text
/setnerkh YOUR_NEW_TOKEN
```

روش دو مرحله‌ای توصیه می‌شود.

## وضعیت منابع

```text
/nerkhstatus
```

این فرمان نشان می‌دهد:

- Nerkh Token تنظیم شده یا نه
- Token از D1 می‌آید یا Cloudflare Secret
- آخرین منبع/منابع موفق قیمت چه بوده‌اند

Token کامل هیچ‌وقت در پاسخ ربات نمایش داده نمی‌شود.

## حذف Token ذخیره‌شده در ربات

```text
/clearnerkh
```

اگر `NERKH_API_TOKEN` قدیمی هنوز در Cloudflare وجود داشته باشد، بعد از حذف Token D1 ربات دوباره آن را امتحان می‌کند. اگر نمی‌خواهید این اتفاق بیفتد، Secret قدیمی Cloudflare را هم حذف کنید.

## لغو حالت ورود API

```text
/cancel
```

حالت انتظار برای Token حدود ۱۰ دقیقه اعتبار دارد.

# رفتار Fallback

ترتیب اصلی:

```text
Nerkh.io
   ↓ در صورت خطا/انقضا/ناقص بودن
TGJU
   ↓ در صورت خطا/ناقص بودن
Navasan/GitHub
   ↓ اگر هنوز نمادی موجود نبود
آخرین مقدار سالم D1
```

اگر Nerkh خطای دسترسی مانند 401/402/403 بدهد، اثر انگشت Token نامعتبر در D1 ثبت می‌شود و Worker در هر دقیقه همان Token خراب را دوباره صدا نمی‌زند. وقتی Token جدید را با `/setnerkh` وارد کنید، این وضعیت پاک می‌شود و Nerkh دوباره منبع اول می‌شود.

TGJU داده‌ها را به ریال می‌دهد و کد آن‌ها را به تومان تبدیل می‌کند. آینه Navasan/GitHub در وضعیت فعلی دلار، یورو، طلای ۱۸ و سکه امامی را پوشش می‌دهد؛ اگر USDT در آن موجود نباشد و دو منبع بالاتر هم قطع باشند، آخرین USDT سالم D1 حفظ می‌شود.

# نصب / جایگزینی

فایل‌های این ZIP را روی نسخه فعلی پروژه Replace کنید.

اگر پروژه شما اسکریپت npm دارد:

```powershell
npm test
npm run deploy
npx wrangler tail
```

یا تست مستقیم این بسته:

```powershell
node --test test/bot.test.js
```

در این نسخه باید **۲۱ تست** موفق باشد.

## متغیرهای لازم

موارد قبلی:

```text
TELEGRAM_BOT_TOKEN
TELEGRAM_CHAT_ID
TELEGRAM_WEBHOOK_SECRET
DB (D1 binding)
```

مورد جدید برای امنیت فرمان‌های مدیریت:

```text
TELEGRAM_ADMIN_USER_ID
```

`NERKH_API_TOKEN` دیگر اجباری نیست. اگر وجود داشته باشد، تا زمانی که Token ذخیره‌شده در D1 ندارید به‌عنوان Token اولیه/پشتیبان استفاده می‌شود.

هیچ جدول جدیدی لازم نیست؛ همان جدول `bot_state` استفاده می‌شود.

# نکته مهم درباره منابع رایگان

TGJU و آینه GitHub منابع رایگان و بدون API Key هستند، اما API قراردادیِ تضمین‌شده برای این پروژه محسوب نمی‌شوند و ممکن است ساختار یا دسترسی آن‌ها در آینده تغییر کند. دلیل استفاده هم‌زمان از سه منبع همین است تا خرابی یک منبع باعث توقف کامل ربات نشود.
